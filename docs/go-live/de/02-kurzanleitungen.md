# Kurzanleitungen

Jede Karte auf eine eigene Seite drucken (A5 oder A6), laminieren und neben die Tablets legen. Die Einzelheiten stehen im Handbuch (`01`).

---

## Karte 1: Jeden Tag (alle Mitarbeiter:innen)

**Anmelden:** die App auf dem Startbildschirm des Tablets → E-Mail-Adresse und Passwort.

1. **Startseite** → auf **Ihre Gruppe** tippen.
2. Ein Kind kommt → **„Ankommen“**. Abgeholt → **„Abholen“**. Falsch getippt → **„Rückgängig“**.
3. Ein Kind kommt nicht → **„Abwesend“** → Grund, von, bis.
4. **„Achtung“** neben einem Namen = Allergie oder Erkrankung: auf den Namen tippen, den roten Kasten lesen.
5. **Beim Abholen:** Profil des Kindes → **„Wer abholen darf“**: Name und Foto müssen passen. Wenn nicht: Das Kind bleibt, einen Elternteil anrufen.
6. Etwas ist passiert → **„Vorfall melden“**: was, wann, wer informiert wurde.
7. Etwas stimmt mit der App nicht → **„Feedback“** (keine Namen von Kindern).

**„Abmelden“**, bevor Sie das Tablet weitergeben.

---

## Karte 2: Notfall (alle Mitarbeiter:innen)

**Feuer, Räumung, Stromausfall droht:**

1. Seite der Gruppe → **„Notfallliste (PDF)“**, oder Startseite → **„Notfallliste der ganzen Kita (PDF)“**.
2. Drucken, oder das Tablet mitnehmen.
3. Sie zeigt, **wer gerade da ist**, ihre **Allergien und Erkrankungen** und **wen man anruft**.

**Die App öffnet sich nicht?** Die heute Morgen gedruckte Liste nehmen (siehe die Start-Checkliste) und die Admin anrufen.

## Karte 3: Admins

| Aufgabe | Wo |
|---|---|
| Neue Kollegin | „Mitarbeiterkonten“ → „Neue:r Mitarbeiter:in“ → E-Mail, Rolle → „Konto anlegen“ |
| Kollegin geht | „Mitarbeiterkonten“ → „Deaktivieren“ (am selben Tag) |
| Neues Kind | „Kinder“ → „Neues Kinderprofil“; dann auf dem Profil: Gruppe, Allergien, Eltern, Notfallkontakte, abholberechtigte Personen, Einwilligungen |
| Einwilligung erteilt oder widerrufen | Profil des Kindes → „Einwilligungen“ → eintragen, mit Datum |
| Kind geht | Profil des Kindes → „Löschen“ (kommt ins „Archiv“, nach 12 Monaten endgültig gelöscht) |
| Aus Versehen gelöscht | „Archiv“ → „Wiederherstellen“ |
| Ein Elternteil fragt nach seinen Daten | Seite des Elternteils → „Alle Daten exportieren (ZIP)“ |
| Ein Elternteil verlangt die Löschung | Seite des Elternteils → „Alle Daten löschen“ → „Endgültig löschen“ (nicht rückgängig zu machen) |
| Wer hat die Daten eines Kindes angesehen | Profil des Kindes → „Protokoll zu diesem Kind“ |
| Neues Schuljahr | „Kalender“ → „Feiertage und Ferien“ → die neuen .ics-Dateien übernehmen |
| Eine Warn-E-Mail vom Server | Das Betriebshandbuch, im Büro |
