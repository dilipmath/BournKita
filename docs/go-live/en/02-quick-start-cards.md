# Quick-start cards

Print each card on its own page (A5 or A6), laminate it, and keep it next to the tablets. The user manual (`01`) has the details.

---

## Card 1: Every day (all Staff)

**Log in:** the app on the tablet's home screen → email address and password.

1. After logging in, your Group's **Today** opens (several Groups: tap **your Group's tile**).
2. A Child arrives → **"Check in"**. Picked up → **"Check out"**. Wrong tap → **"Undo"**.
3. A Child is not coming → **"Absent"** → reason, from, until.
4. **"Alerts"** next to a name = allergy or medical condition: tap the name, read the red box.
5. **At pick-up:** **"Check out"** shows **who may pick up**: name and photo must match, then **"Goes home now"**. If not: **"Not now"**, the Child stays, call a Parent.
6. Something happened → **"Report incident"**: what, when, who was informed.
7. Something wrong with the app → **"Feedback"** (no Children's names).

**Your name (top right) → "Log out"** before you hand the tablet on.

---

## Card 2: Emergency (all Staff)

**Fire, evacuation, power cut coming:**

1. **"Emergency"** (top of every page) → **"Emergency list (PDF)"** of the Group, or **"Emergency list of the whole Kita (PDF)"**.
2. Print it, or take the tablet.
3. It lists **who is here right now**, their **allergies and conditions**, and **whom to call**.

**The app does not open?** Take the paper list printed this morning (see the go-live checklist) and call the Admin.

## Card 3: Admins

| To do | Where |
|---|---|
| New colleague | "Staff accounts" → "New Staff member" → email, Role → "Create account" |
| Colleague leaves | "Staff accounts" → "Deactivate" (the same day) |
| New Child | "Children" → "New Child profile"; then on the profile: Group, allergies, Parents, Emergency contacts, pick-up persons, Consents |
| Consent given or withdrawn | Child's profile → "Consents" → record it, with the date |
| Child leaves | Child's profile → "Delete" (goes to the "Archive", purged after 12 months) |
| Deleted by mistake | "Archive" → "Restore" |
| A Parent asks for their data | Parent's page → "Export all data (ZIP)" |
| A Parent asks for deletion | Parent's page → "Delete all data" → "Delete permanently" (cannot be undone) |
| Who looked at a Child's data | Child's profile → "Audit log for this Child" |
| New school year | "Calendar" → "Holidays" → import the new .ics files |
| A warning email from the server | The admin runbook, in the office |
