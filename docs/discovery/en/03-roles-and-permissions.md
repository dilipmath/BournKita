# Roles and permissions

Every Staff member has exactly one Role: **Admin**, **Teacher** or **Guest**. This is who may do what in the app **today**. For each row, tick "OK" or write what should change.

✓ = may do it  ✗ = may not

| What | Admin | Teacher | Guest | OK? | Change |
|---|:-:|:-:|:-:|:-:|---|
| Log in; reset a forgotten password | ✓ | ✓ | ✓ | ☐ | |
| Kita-wide Calendar: the whole Kita's Events and Holidays (read) | ✓ | ✓ | ✓ | ☐ | |
| Group Calendars, Group Events and Children's Birthdays (read) | ✓ | ✓ | ✗ | ☐ | |
| Add, change and delete Events | ✓ | ✓ | ✗ | ☐ | |
| Today view: Children here, Alerts, Birthdays | ✓ | ✓ | ✗ | ☐ | |
| Check Children in and out; record Absences | ✓ | ✓ | ✗ | ☐ | |
| Read Child profiles (Parents, contacts, Alerts, Consents, photos) | ✓ | ✓ | ✗ | ☐ | |
| Create, change and delete Child profiles and Parents; record Alerts, Consents and photos | ✓ | ✗ | ✗ | ☐ | |
| Create, rename and remove Groups; put Children into Groups | ✓ | ✗ | ✗ | ☐ | |
| Task board and Backlog of every Group | ✓ | ✓ | ✗ | ☐ | |
| Print the Emergency list (one Group or the whole Kita) | ✓ | ✓ | ✗ | ☐ | |
| Report an Incident | ✓ | ✓ | ✗ | ☐ | |
| See Incidents | all | own | ✗ | ☐ | |
| Add a Follow-up to an Incident | ✓ | ✗ | ✗ | ☐ | |
| Archive: see deleted Child profiles and restore them | ✓ | ✗ | ✗ | ☐ | |
| Parent data: export it, or delete it for good on request | ✓ | ✗ | ✗ | ☐ | |
| Audit log: who viewed or changed which Child's data | ✓ | ✗ | ✗ | ☐ | |
| Staff accounts: create, change Role, deactivate, assign Groups | ✓ | ✗ | ✗ | ☐ | |
| Import Holidays from an iCal file | ✓ | ✗ | ✗ | ☐ | |
| Send Feedback (problem, change request, idea) | ✓ | ✓ | ✓ | ☐ | |

Also always true:

- A Guest never sees personal data, gets no Reminder emails and is never given Tasks.
- Every view and change of a Child's data is recorded in the Audit log.
- There must always be at least one active Admin.
