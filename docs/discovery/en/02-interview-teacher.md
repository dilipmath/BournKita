# Interview: Teacher

Name: ______________________  Group: ______________________  Date: ____________

About 30 minutes. Print this sheet once per Teacher (at least two). Let them try the app on a tablet: picking their Group, the Today view, checking a Child in and out, opening a Child profile, the Task board.

## 1. Your day

- Walk me through yesterday, from arriving to leaving. What did you look up, write down or tell a colleague?
- What do you need to know about a Child at a glance (allergies, who picks up, Absences, Birthdays)?
- What do you write on paper today that you would rather not?

## 2. Trying the app

Watch them; note where they hesitate or tap the wrong thing.

| Task | Easy | Hard | What happened |
|---|---|---|---|
| Log in and pick your Group | ☐ | ☐ | |
| See which Children are here and their Alerts | ☐ | ☐ | |
| Check a Child in, then out | ☐ | ☐ | |

| Find who may pick a Child up | ☐ | ☐ | |
| Add a Task to the board and move it | ☐ | ☐ | |
| Add an Event to the Group's Calendar | ☐ | ☐ | |
| Report an Incident (a fall in the garden) | ☐ | ☐ | |
| Print the Emergency list | ☐ | ☐ | |

## 3. Questions

- When during the day would you use it: at the door, in the group room, in breaks?
- On which device? Is there a tablet in your group room?
- Is anything missing that you would need every day?
- Is anything there that you would never use?
- German or English, or both?
- Anything that worries you about using it (time, data protection, mistakes)?
