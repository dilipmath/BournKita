# Interview: Erzieher:in

Name: ______________________  Gruppe: ______________________  Datum: ____________

Etwa 30 Minuten. Dieses Blatt einmal pro Erzieher:in drucken (mindestens zwei). Lassen Sie sie die App auf einem Tablet ausprobieren: die eigene Gruppe wählen, „Heute“, ein Kind ankommen und abholen lassen, ein Kinderprofil öffnen, die Aufgaben.

## 1. Ihr Tag

- Beschreiben Sie den gestrigen Tag, vom Ankommen bis zum Gehen. Was haben Sie nachgeschaut, aufgeschrieben oder einer Kollegin gesagt?
- Was müssen Sie über ein Kind auf einen Blick wissen (Allergien, wer abholt, Abwesenheiten, Geburtstage)?
- Was schreiben Sie heute auf Papier, das Sie lieber nicht mehr aufschreiben würden?

## 2. Die App ausprobieren

Zuschauen; notieren, wo sie zögern oder das Falsche antippen.

| Aufgabe | Leicht | Schwer | Was ist passiert |
|---|---|---|---|
| Anmelden und die eigene Gruppe wählen | ☐ | ☐ | |
| Sehen, welche Kinder da sind, und ihre Allergien und Erkrankungen | ☐ | ☐ | |
| Ein Kind ankommen lassen, dann abholen | ☐ | ☐ | |
| Eine Abwesenheit eintragen (morgen krank) | ☐ | ☐ | |
| Nachsehen, wer ein Kind abholen darf | ☐ | ☐ | |
| Eine Aufgabe anlegen und verschieben | ☐ | ☐ | |
| Einen Termin in den Kalender der Gruppe eintragen | ☐ | ☐ | |
| Einen Vorfall melden (Sturz im Garten) | ☐ | ☐ | |
| Die Notfallliste drucken | ☐ | ☐ | |

## 3. Fragen

- Wann am Tag würden Sie die App nutzen: an der Tür, im Gruppenraum, in Pausen?
- Mit welchem Gerät? Gibt es ein Tablet in Ihrem Gruppenraum?
- Fehlt etwas, das Sie jeden Tag bräuchten?
- Gibt es etwas, das Sie nie nutzen würden?
- Deutsch oder Englisch, oder beides?
- Macht Ihnen etwas Sorgen bei der Nutzung (Zeit, Datenschutz, Fehler)?
