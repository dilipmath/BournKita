# Rollen und Rechte

Jede:r Mitarbeiter:in hat genau eine Rolle: **Admin**, **Erzieher:in** oder **Gast**. So ist **heute** in der App geregelt, wer was darf. Bitte in jeder Zeile „OK“ ankreuzen oder notieren, was anders sein soll.

Außerdem gilt immer:

- Ein Gast sieht nie personenbezogene Daten, bekommt keine Erinnerungen per E-Mail und keine Aufgaben.
- Jedes Ansehen und Ändern von Daten eines Kindes wird im Protokoll festgehalten.
- Es muss immer mindestens ein:e aktive:r Admin geben.

## Fragen

- Soll die Stellvertretung Admin sein, oder braucht es eine Rolle zwischen Admin und Erzieher:in?
- Sollen Erzieher:innen nur die Kinder ihrer eigenen Gruppe(n) sehen, oder alle Kinder (wie jetzt)?
- Wird die Rolle **Gast** überhaupt gebraucht? Wenn ja, wer würde sie nutzen (z. B. Küche, Praktikant:in, Träger)? Wenn niemand, kann sie entfallen.
- Gibt es etwas, das Erzieher:innen können müssen, was heute nur Admins dürfen (z. B. eine Allergie eintragen)?
